# PayLink Demo Website (Vercel-ready)

This is a simple Next.js + Tailwind demo site for Conrad Challenge submission.
It includes:
- Landing page + pricing
- Interactive demo (members + transactions + n-bbang settlement)
- A lightweight animated model (notification → ledger)
- A clean Innovation Image (SVG) at `/innovation-image.svg`

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1) Create a GitHub repo and push this project
2) Go to Vercel → New Project → Import repo
3) Deploy (defaults work)

## Conrad Challenge fields
- Website URL: use your Vercel deployment URL
- Innovation Image: upload a screenshot OR download `/innovation-image.svg`
